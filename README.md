# TFGinder — Ionic & Firebase Learning App

An educational mobile/web application with Ionic screens and Firebase integration.

## Scope

The module configures Authentication, Firestore and Storage, including a native-platform authentication persistence branch. It is teaching/application source, not proof of a currently operating matching service.

## Technology / Material

Ionic 6 · Angular 13 · Firebase 9 · AngularFire · Capacitor

## Repository guide

- [package.json](package.json)
- [src/app](src/app)
- [firebase.json](firebase.json)

## Getting started / Reproducibility

Review the Firebase configuration and use your own project settings. Install compatible dependencies in the repository root and use `npm start` for the web development server. Native targets require their own toolchains.
